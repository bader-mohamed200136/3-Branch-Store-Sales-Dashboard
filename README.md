A business intelligence dashboard built to evaluate sales, profitability, and operational performance across 3 retail branches.

Features
	•	Revenue, profit, and cost KPIs
	•	Profit margin analysis
	•	Top-performing products
	•	Revenue vs profit analysis
	•	Sales trend monitoring
	•	Branch performance comparison
	•	Sales by payment method and channel

Tools Used
	•	Power BI
	•	Excel
	•	DAX
	•	Data Modeling
	•	KPI Design
